# Индикаторы TradingView

Индикаторы, присланные 2026-10-17, — исходники Pine Script v5 как есть, для идей ботов.
План проверки — `docs/backlog.md`. Множитель пунктов для золота — 1, разметка на H1.

| Файл | Что строит | Для бота |
|---|---|---|
| `01-trend-decoder.pine` | две зоны отката на √(6.18·R) и √(9·R) от конца движения (R — размах в USD) и вдвое ближе; цель — √(6.18·R)/10 | глубина отката зависит от размаха: 10 USD → 79–95 %, 30 → 45–55 %, 100 → 25–30 % |
| `02-time-retracement.pine` | время отката: через R·10/3 баров от конца движения | ≈3.3 бара H1 на 1 USD; рост волатильности 2024→2026 растянул прогноз в 3 раза |
| `03-price-action-concepts-limonfx.pine` | структура BOS / CHoCH / CHoCH+ (внутренняя 5, свинговая 50), тренд M15–D1, ордер-блоки, FVG, EQH/EQL, premium/discount, накопление/распределение | лицензия CC BY-NC-SA. Объём — тиковый. Уровни D/W/M берутся с `lookahead_on`: на истории видят будущее |
| `04-vibration-cycles.pine` | 10 зон от конца движения: числа диагоналей квадрата девяти (9, 17, 25, 37, 49, 65, 81, 101, 121, 145) × P, P = max(⌊R/100⌋, 1) | при R < 200 USD зоны стоят на фиксированных USD; покрывают ≈25 % цены до 151 USD |
| `05-numerology-secret.pine` | 12 зон на фиксированных USD от одного экстремума (8–10 … 189–195) | почти та же сетка, что в 04; покрывают ≈28 % цены до 195 USD |

Во всех, кроме 03, точки ставятся вручную. Боту нужно своё правило выбора размаха. Сначала
пробуем `Include/Levels/AtrZigZag.mqh`: последний размах H1 не меньше N ATR.
