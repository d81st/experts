# Демо-форвард двух ботов: как запустить (2026-11-28)

Цель — проверить **исполнение** (спред, проскальзывание, перерывы сессии) у кандидатов из
предрегистрации `docs/prereg/2026-11-28-alchemist-long24-asia-5r.md`. Преимущество решается не
здесь, а прогоном холдаута в конце окна. Только демо-счёт.

## Что нужно от владельца

1. **Машина, которая всегда включена** и на которой работает MetaTrader 5 (Windows):
   - VPS (виртуальный сервер Windows у любого хостинга) — лучший вариант;
   - встроенный «Виртуальный хостинг» в самом MT5 (платная подписка MetaQuotes) — переносит
     советников на сервер в один клик;
   - домашний компьютер, который не выключается и не засыпает.
   Раннер GitHub Actions для этого не подходит: терминал между запусками не живёт.
2. **Демо-счёт Exness** (MT5, тип Standard, валюта USD), баланс около **10 000 USD** — тогда
   результаты сравнимы с тестером. Пароль в репозиторий и в чат не писать.

## Шаги

1. Установить MetaTrader 5 Exness с официального сайта Exness, войти в демо-счёт.
2. Взять из репозитория (ветка `main`) папки `Include/` и `hybrid/`, положить в
   `MQL5\Experts\experts\` (чтобы пути `#include "../Include/..."` находились). Скомпилировать
   в MetaEditor `hybrid-alchemist_v1.0.mq5` и `hybrid-asia-breakout_v1.1.mq5`.
3. Скопировать пресеты в `MQL5\Presets\`:
   - `research/demo-forward/candidate-long24.set` — Alchemist «только покупки, выход 24 бара»;
   - `research/demo-forward/candidate-asia-5r.set` — пробой Азии, тейк 5R, до 120 часов.
4. Открыть два графика XAUUSDm:
   - **H1** → перетащить `hybrid-alchemist_v1.0` → вкладка «Входные параметры» → «Загрузить» →
     `candidate-long24.set`;
   - **M15** → `hybrid-asia-breakout_v1.1` → загрузить `candidate-asia-5r.set`.
5. Включить кнопку «Алгоритмическая торговля». На каждом графике в углу должна быть «улыбка»
   советника. В журнале «Эксперты» — строки `✅ Hybrid Alchemist…` и `✅ Hybrid Asia Breakout…`
   с теми же параметрами (риск 1 %, выход 24 / тейк 5R, удержание 120 ч).
6. Проверить, что у ботов разные магики: Alchemist **71012**, пробой Азии **71007**.

## Что присылать раз в неделю (или месяц)

- Файл журнала сделок `TradeJournal_XAUUSDm.csv` из общей папки терминала
  (`Файл → Открыть каталог данных → ...\Common\Files`) — без номера счёта.
- Или отчёт «История» из терминала (правый клик в «Истории» → «Отчёт» → HTML), предварительно
  без логина и сервера.

По ним — сверка с тестером на тех же днях (`tester/tools/demo_report.py`, бэктестер `compare`):
совпадают ли входы, выходы, проскальзывание. Правила ботов до конца окна холдаута не меняются.

## Ограничения

- Автоматический ежедневный экспорт (`tools/demo-forward-export.mq5`, воркфлоу
  `demo-forward-monitor`) сейчас знает только Alchemist (магик 71012). Если оба бота пойдут на
  демо, экспорт нужно расширить на магик 71007 — это следующий шаг после запуска.
- Общий лимит риска счёта (`MaxAccountRiskPercent`) в пресетах выключен (0): при двух ботах по
  1 % одновременно в одну сторону бывает не больше 2 % (`tester/results/portfolio.md`). Включать
  ли страховку 3 % — решение владельца; пресет Alchemist тогда поменяется вместе с проверкой
  `tools/demo_forward_export.py`.
