## Что будет, когда окно закончится

1. После 2027-12-31: выгрузить тики Exness за окно (воркфлоу `export-ticks`), запустить тестер MT5
   с параметрами выше **один раз** (конфиг с ключом `holdout_prereg`, ссылающимся на этот файл —
   проверка `tools/check_inputs.py` без него прогон в холдаут не пропустит).
2. Посчитать критерии из этого файла. Записать результат в `tester/results/`, не меняя ни
   параметров, ни критериев.
3. Если критерии выполнены — гипотеза принята; если нет — отвергнута; если сделок меньше 100 —
   «ни да, ни нет».

Демо-форвард идёт параллельно и в решение по этому файлу не входит — он проверяет исполнение
(сверка с бэктестером), а не преимущество.
