# Тестирование на GitHub Actions

Тест запускается автоматически при изменении файла настроек `tester/*.json`
(сценарий `.github/workflows/backtest.yml`) и прогоняет **все** файлы настроек по очереди:
`liq-grab.json`, `crt-bot.json`, `engulfing.json`. Вручную: Actions → Backtest MQL5 →
Run workflow, поле «only» — имя одного файла без `.json` (пусто — все боты).
Результаты публикуются в ветку `tester-results`, папка `run-<id прогона>/`.
Сводки с выводами — в `tester/results/`.

## Эталонные настройки (не меняются)

Самые близкие к реальной торговле. Все версии ботов сравниваются только на них.

| Параметр | Значение | Почему |
|---|---|---|
| Сервер | демо Exness (`MT5_SERVER` в секретах) | тот же брокер, что на реале |
| Символ | `XAUUSD` (на демо нет `XAUUSDm`) | золото |
| Модель | `4` — каждый тик на основе реальных тиков | реальная тиковая история брокера |
| Задержка исполнения | `200` мс, фиксированная | реальный пинг до сервера Exness ~200 мс; фиксированная, чтобы прогоны были сравнимы между собой |
| Период | 2026.07.06 – 2026.10.05 | фиксированный, чтобы сравнивать версии на одних и тех же данных |
| Депозит / плечо | 200 USD / 1:2000 | как на реальном счёте |

Параметры самого бота (`expert`, `period` и входные параметры) — то, что меняется
от теста к тесту.

## Поля файла настроек

| Поле | Значение |
|---|---|
| `expert` | имя бота без `.mq5` |
| `symbols` | список символов; берётся первый, который есть на сервере |
| `period` | таймфрейм графика (`M3`) |
| `from`, `to` | период теста, `ГГГГ.ММ.ДД` |
| `model` | 0 — все тики, 1 — OHLC M1, 2 — цены открытия, 4 — реальные тики |
| `delay` | задержка исполнения в мс; 0 — без задержки, -1 — случайная |
| `deposit`, `currency`, `leverage` | депозит, валюта, плечо `1:N` |
| `inputs` | необязательно: параметры бота, например `{"TrailingMode": 0}`; для `variants` — общие значения, которые вариант может переопределить. Указывайте здесь **все** параметры, которые меняет хотя бы один вариант |
| `variants` | необязательно: несколько прогонов за раз, `[{"name": "be-off", "inputs": {...}}, ...]`; имя варианта добавляется к имени отчёта |

## Разбор отчёта

```
python3 tester/tools/parse_report.py <report.htm>
```
