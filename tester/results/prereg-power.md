# Мощность проверки на холдауте (2026-11-28)

Скрипт `tester/tools/prereg_power.py`. Вопрос: какой шанс у бота пройти критерии из
предрегистрации `docs/prereg/2026-11-28-alchemist-long24-asia-5r.md`, если у него действительно
есть преимущество. Сделки кандидатов 2024 — 2026-10-15 (Alchemist long x24 — 242, пробой Азии 5R —
230; движок сверен с MT5), бутстрэп «холдаутов» по N сделок, 2000 моделей, внутренний бутстрэп
1000. Три сценария: преимущество как на истории, вдвое меньше (из каждой сделки вычтена половина
среднего R), нулевое.

## Черновые критерии (граница 97.5 % PF > 1, просадка ≤ 15 %, стресс спреда по границе)

| Шанс пройти, N = 100 | Как на истории | Вдвое меньше | Нулевое (ложное «да») |
|---|---|---|---|
| Alchemist long x24 | 26 % | 5 % | 0.7 % |
| Пробой Азии 5R | 18 % | 4 % | 0.6 % |

**На 100 сделках черновые критерии почти наверняка отвергнут и настоящего бота:** даже с
преимуществом как на истории шанс пройти — 1 из 4–5. Главное узкое место — нижняя граница
двустороннего интервала 97.5 % и стресс «по границе»; просадка 15 % режет в основном пробой Азии
(просадка ≤ 15 % в 85 % случаев даже при полном преимуществе).

## Мягче: односторонняя граница 95 % PF > 1, просадка ≤ 20 %, стресс по точечному PF > 1

| Шанс пройти | N = 100: как на истории / вдвое меньше / нулевое | N = 250: как на истории / вдвое меньше / нулевое |
|---|---|---|
| Alchemist long x24 | 57 % / 22 % / 4.0 % | 90 % / 41 % / 4.9 % |
| Пробой Азии 5R | 47 % / 18 % / 3.9 % | 76 % / 28 % / 4.2 % |

Ложное «да» при нулевом преимуществе остаётся около 4–5 % — это и есть уровень значимости 5 %.

## Вывод

1. Честно доказать **скромное** преимущество (вдвое меньше исторического — самый вероятный
   случай) на одном холдауте за 14 месяцев нельзя: нужно 500+ сделок, это 5–6 лет.
2. Поэтому разумнее не «да / нет», а **три исхода**, заданные заранее:
   - **отказ** — точечный PF в R < 1 или просадка > 20 %: бота выключаем;
   - **продолжить** — точечный PF > 1, но односторонняя 95 % граница ≤ 1: бот остаётся на демо
     (или минимальном риске), следующая контрольная точка — на 250 сделках с теми же правилами;
   - **принять** — односторонняя 95 % граница PF > 1, просадка ≤ 20 %, стресс спреда +0.20 и
     +0.50 USD с точечным PF > 1.
   При таком правиле настоящий бот почти не рискует быть выключенным по ошибке (шанс «отказа» при
   преимуществе как на истории — около 3–5 %), а бот без преимущества принимается не чаще 5 %.
3. Решение за владельцем; поправка вносится в предрегистрацию **до** конца окна и до любого
   взгляда на холдаут (это допустимо: холдаут ещё не читали).
