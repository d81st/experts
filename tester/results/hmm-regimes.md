# Идея из науки 4: скрытые марковские модели (HMM) на D1 (2026-11-28)

Скрипт `tester/tools/hmm_filter.py`. Гауссова HMM по дневным лог-доходностям золота (своя
реализация, Баум–Велч). **Обучение только на 2017–2023** (дневные бары из часовой истории
Exness), параметры заморожены; на 2024 — 2026-10-15 — фильтрованная вероятность состояний (только
по прошлому), бот видит состояние последнего закрытого дня. 18 фильтров, поправка на перебор —
максимум z случайных 1.82 в медиане.

## Модели (обучены на 2017–2023)

| Модель | Состояния: среднее % в день, разброс % в день | Доля дней 2024 / 2025 / 2026 |
|---|---|---|
| 2 состояния | спокойное +0.034, 0.64; бурное +0.025, 1.40 | спокойное 75 % / 67 % / **18 %** |
| 3 состояния | «вялое» +0.009, 0.84; «флэт» +0.028, 0.59; «рывок» +0.175, 1.76 | рывок 5 % / 21 % / 57 % |

2026 год модель почти целиком относит к «бурному» режиму — такого раньше не было.

## Результат (R на сделку, 2024 / 2025 / январь–май 2026)

| Бот | Без фильтра | Только спокойное (HMM-2) | Только бурное |
|---|---|---|---|
| Alchemist H1 x12 | +0.05 (154) / +0.05 (166) / +0.21 (56) | **+0.12 (121) / +0.09 (123) / +0.51 (14)**, p 0.057 | −0.19 / −0.11 / +0.10 |
| Alchemist long x24 | +0.15 / +0.23 / +0.42 (21) | +0.21 / +0.31 / +1.35 (5) | −0.19 / −0.08 / +0.22 |
| Пробой Азии 5R | +0.08 / +0.30 / +1.04 (23) | +0.11 / +0.25 / +1.95 (7) | −0.21 / +0.14 / +0.66 |

- **Ни один фильтр не принят:** «только спокойное» у Alchemist лучше базы во всех трёх периодах,
  но в 2026 году спокойных дней почти не было (14 и 5 сделок) — порог ≥ 20 не выполнен, поправку
  не проходит (p_max 0.64).
- **В бурном режиме Alchemist теряет** в 2024–2025 — тот же вывод, что у энтропии и Хёрста
  (`science-filters.md`): не входить в растянутое, бурное движение.
- 3 состояния — без пользы (почти все сделки вне «флэта»).
- У пробоя Азии фильтр «по среднему состояния» оставляет только покупки — это рост золота, а не
  режим.

## Вывод

Для ботов ничего не меняем. Гипотеза на будущее (третья с тем же смыслом): **Alchemist лучше в
спокойном режиме** — проверять только на холдауте.
