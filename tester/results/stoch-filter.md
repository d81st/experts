# Стохастик как фильтр готовых ботов (2026-11-23)

Скрипт `tester/tools/stoch_filter.py`. Минутки до 2026-10-15 23:59. Отдельный вход
по стохастику уже отвергнут в `screening.md` (48 вариантов). Здесь сигнал бота
не меняется, стохастик только решает, пропускать ли его.

Индикатор — настройки по умолчанию в MetaTrader 5: %K 5, %D 3, замедление 3.
Два фильтра, уровни не перебирались:
- линии согласны со стороной сделки;
- покупка только при %K < 80, продажа только при %K > 20.

Боты: Alchemist H1, выход 12 часов, структура D1; пробой Азии M15, тейк 5R.
Фильтр принимается, только если средний R выше базы во всех трёх периодах
подбора, сделок не меньше 20 и p ≤ 0.05. Июнь–15 октября 2026 в решение не входил.

и в отсеве именно он давал вклад, а не соседний фильтр.
