# Конструктор ботов (2026-10-24, `tester/tools/constructor.py`)

Перебор сочетаний «вход × фильтры × выход» из уже проверенных блоков. Золото, минутные бары,
спред 0.25 USD, своп покупок; одна позиция за раз; результат в R. Подбор — 2024, 2025,
январь–май 2026; июнь–октябрь 2026 — контроль, открыт один раз для заранее выбранных финалистов.

## Блоки

| Часть | Варианты |
|---|---|
| Вход (8) | Alchemist H1 / H2 / H4 (вход по рынку, стоп 3 ATR); пробой структуры BOS H1 / H4 (так же); лимитки FVG M15 / M30 / H1 с настройками FVG-робота |
| Тренд D1 (3) | выкл. / структура D1 / закрытие D1 против EMA50 |
| Сессия (3) | весь день / 07–20 / 12–20 (сервер, UTC+0) |
| Режим (3) | выкл. / только тренд (ER D1 20 ≥ 0.3) / только флэт |
| Новости (2) | выкл. / нет входа ±60 минут от NFP, CPI, FOMC, ISM |
| Выход (8) | тейк 3 / 5 / 10R; половина на 2R + безубыток + 6R; по времени 12 / 24 часа; трейлинг: с +1R на расстоянии 1R, с +2R на 1.5R |

Всего 3456 сочетаний. Каждое сравнивается со случайными входами (тот же период, час,
направление, стоп и выход). Поправка на перебор — максимум z по всем сочетаниям на случайных
данных.

**Сверка с прежними расчётами:** Alchemist H4 с выходом через 12 часов — PF 1.63, 225 сделок
(как в проверке Alchemist). FVG H1 с тейком 10R — те же входы, что у робота; в контроле +0.155R
на 38 сделках (в разборе робота +0.16R на 38).

## Результат подбора

**Поправку на перебор не прошло ни одно сочетание.** Лучший z — 3.5; у случайных данных
максимум z по 3456 сочетаниям — 3.9 в медиане, 4.5 в 90 % случаев.

Что видно по блокам (средний z по всем 54 сочетаниям фильтров):

| Вход | лучший выход | средний z |
|---|---|---|
| Alchemist H1 | трейлинг 1R | 1.8 |
| Alchemist H2 | половина на 2R + 6R | 1.4 |
| Alchemist H4 | по времени 12 ч | 1.3 |
| BOS H4 | по времени 24 ч | 1.5 |
| FVG H1 | тейк 10R / трейлинг 2R | 1.4 |
| BOS H1, FVG M15, FVG M30 | — | ниже 1 |

- **Фильтры почти ничего не добавляют.** Тренд D1, сессия, режим и новости не улучшают ни
  один вход устойчиво; лучшие сочетания — в основном без фильтров. Небольшой плюс от структуры
  D1 у Alchemist H1/H2 — он уже включён в боте.
- **FVG работает только на H1 и с тейком 10R**, как в роботе. Трейлинг на FVG с ATR-стопом хуже.
  (В первом прогоне блок FVG по ошибке был в старой версии с долларовым стопом 2–5 USD; там
  трейлинг выглядел лучше, а тейк 10R в контроле дал 28 убытков подряд. К роботу это не
  относится.)
- **Alchemist с выходом по R** (тейк 5R или трейлинг 1R, удержание до 5 суток) на подборе
  заметно лучше выхода по времени: +0.19…+0.36R на сделку против +0.05…+0.07R.

## Выводы

1. **Новых сочетаний лучше нынешних ботов конструктор не нашёл.** Alchemist (H1, структура D1,
   выход по времени) и FVG-робот (H1, тейк 10R) — уже лучшие или почти лучшие в своих семьях.
2. **Фильтры сессии, режима и новостей можно не добавлять** — устойчивой пользы нет.
3. **Кандидаты на будущее** (в контроле в плюсе, но не лучше случайных): Alchemist с выходом
   по R (тейк 5R / половина на 2R) и BOS H4 с выходом через 24 часа (мало сделок).
