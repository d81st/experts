# Идеи из науки 1–3: Хёрст, энтропия, Калман как фильтры (2026-11-28)

`docs/ideas-science.md`, раздел 4, пункты 1–3. Скрипт `tester/tools/science_filters.py`,
минутки XAUUSDm до 2026-10-15, движок `constructor.py`. Сигнал бота не меняется, фильтр
пропускает или отбрасывает его; значения — по последнему закрытому бару H1 или D1; пороги
заданы заранее. 44 фильтра; поправка на перебор — максимум z случайных 2.22 в медиане.
Порог принятия: лучше бота без фильтра во всех трёх периодах (≥ 20 сделок), p ≤ 0.05,
p_max ≤ 0.10.

**Итог: ни один фильтр не принят.** R на сделку: 2024 / 2025 / январь–май 2026 (сделок).

## 1. Показатель Хёрста (коэффициент дисперсий Ло–Маккинли)

- Неожиданно: **«тренд» по Хёрсту (VR > 1) — хуже базы у всех ботов**, а «возврат к среднему»
  (VR < 1) — чуть лучше. Часто «память» в часовых изменениях означает уже растянутое движение.
- Пробой Азии при VR(H1) < 1: +0.16 (67) / +0.50 (60) / +1.27 (18) против базы +0.08 / +0.30 /
  +1.04 — **лучше во всех трёх периодах**, но в январе–мае 2026 18 сделок (меньше 20), p 0.06,
  p_max 0.91. Гипотеза, не правило.
- На D1 VR > 1 почти не бывает в 2025–2026 (рост золота шёл без «памяти» в дневных изменениях).

## 2. Энтропия знаков изменений

- **Низкая энтропия H1 (из 24 свечей ≥ 2/3 в одну сторону) — плохое время для входа у всех
  ботов:** Alchemist x12 −0.16 / −0.04 / −0.26, long x24 −0.23 / −0.16 / −0.11 — минус во всех
  периодах. Это «растянутое» движение, вход в его конце.
- Зеркальный фильтр «энтропия H1 не низкая» (добавлен после первого прогона — считать
  подсмотренным): long x24 +0.17 (95) / +0.28 (86) / +0.58 (18) против базы +0.15 / +0.23 /
  +0.42 — лучше во всех трёх периодах; x12 +0.07 / +0.05 / +0.32 (2025 — как база). Не проходит
  ни порог по сделкам в 2026, ни p ≤ 0.05 (0.077), ни поправку (p_max 0.97).
- Энтропия D1 — без устойчивого эффекта.

## 3. Фильтр Калмана

- **Скорость Калмана H1 по направлению сделки совпадает с сигналами Alchemist почти всегда** —
  фильтр ничего не отбрасывает (сделки те же, что у базы).
- Калман D1 по направлению сделки: long x24 +0.19 / +0.22 / +0.89 (187, p 0.04) — 2025 чуть хуже
  базы; не принят.
- **Калман D1 вместо структуры D1** у Alchemist — то же самое: x12 +0.072 против +0.073, long x24
  +0.197 против +0.207. Это равноценная замена, выигрыша нет.

## Выводы

1. Для ботов ничего не меняем.
2. Две гипотезы на будущее (обе согласуются с «не входить в конце растянутого движения»):
   - Alchemist — не входить, когда энтропия H1 низкая (24 часа почти всё в одну сторону);
   - пробой Азии — входить при VR(H1) < 1.
   Обе на подборе на грани и подсмотрены; решать можно только на холдауте после предрегистрации.
3. Структура D1 в Alchemist — не хуже «научной» замены (Калман D1).
