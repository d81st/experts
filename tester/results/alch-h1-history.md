# Alchemist на истории H1 2017–2022 (грубая проверка, 2026-11-27)

Пункт 3 порядка владельца от 2026-11-26. Скрипт `tester/tools/alch_h1_history.py`, данные —
часовые бары XAUUSDm Exness (`run-37736874591/data/bars_XAUUSDm_H1.zip`, ветка `tester-results`).
В 2014–2016 баров около 300 в год — настоящая H1-история у Exness начинается в 2017, эти годы
только прогрев индикаторов.

**Исполнение грубое, по H1:** сигнал как в боте (SMA200, HMA21, CCI20 ±100, H4 над/под EMA50,
структура D1 len 5); вход на открытии следующего часа, спред 0.25 USD; стоп 3 ATR14 по
максимуму / минимуму каждого часа (гэп за стоп — выход по открытию); выход по закрытию бара
входа + N − 1; своп покупки 0.49 USD на унцию за ночь; одна позиция. Сравнение — случайные
входы того же года, часа и направления с тем же удержанием и стопом (1000 прогонов).

**2017–2022 при подборе не использовались никогда** — это первая честная проверка вне выборки
для Alchemist. 2023 тоже не смотрели. 2024–2026 — уже смотрели, для сверки.

## Выводы

1. **Alchemist со структурой D1 проходит первую проверку вне выборки:** на 2017–2022 в плюсе
   5 лет из 6 и лучше случайных входов (p 0.006–0.02); в 2023 тоже в плюсе. Это самый сильный
   довод за бота из всех, что у нас были.
2. **Фильтр структуры D1 обязателен для Alchemist:** без него 2017–2022 в минусе (−28R при
   просадке 65R). Решение 2026-10-19 включить его по умолчанию подтверждается.
3. **Вариант «только покупки, выход 24 бара» лучше всех и на старой истории** (+0.10R, просадка
   11.8R за шесть лет). Часть этого — рост золота, но случайные покупки с тем же удержанием
   дают −0.02R, так что выбор момента входа работает.
4. Преимущество небольшое: при спреде вдвое у x12 почти ноль — нужен брокер с узким спредом.

## Оговорки

- Исполнение по часовым барам, без минуток и тиков; порядок внутри часа не известен (у
  Alchemist только стоп и выход по времени, поэтому ошибка невелика).
- Спред фиксированный, своп — сегодняшний.
- Не сверено с MT5 на этих годах (тестер MT5 по H1-барам Exness за 2017–2022 можно запустить
  отдельно).
